# Bohí · Jabones Artesanales

Página web de catálogo para **Bohí**, jabones artesanales naturales hechos a mano en Hidalgo, México.

Sitio estático (HTML, CSS y JavaScript) — belleza natural, hecha a mano.

## Contenido

- **Catálogo** de jabones (Rosa, Lavanda, Caléndula, Manzanilla, Miel & Glicerina, Decorativo Premium) a $85.00 MXN.
- Secciones de **Ingredientes**, **Proceso artesanal**, **Empaque ecológico** y **Contacto**.
- Diseño responsive (móvil, tablet y escritorio).

## Estructura

```
botica-de-jabon/
├── index.html      La página
├── styles.css      Estilos
├── products.js     Catálogo de productos
└── images/         Fotografías
```

## Cómo verlo

Abre `index.html` con doble clic en cualquier navegador. No requiere servidor.
